Overview

This is a basic calculator inspired by Apples calculator design, and built with HTML, CSS, and JavaScript. It incorporates keyboard support, and allows for a more seamless experience with results updating the display in real time for lengthier calculations: 

(e.g. 8 + 8 + (at this point displays 16 on the display) 2 = 16 (display updates to final result of calculation))


Features

- Addition, subtraction, multiplication, division, percentage button, negative button
- Decimal numbers
- Clear button
- Keyboard Support
- Checks for 0 redundancy (e.g. 001 is not allowed, but 100 is)


Conclusion

This exercise was a fun way to flex my CSS (flexbox) and Javascript skills. Though basic, it was an effective practice in logic. For instance, figuring out how to check for whether it was an initial instance of 0 or not, and proceeding with updating the display and variables accordingly (= vs. +=). It was also an enjoyable task to add keyboard support -- something I have had minimal experience with.
